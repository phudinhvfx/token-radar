The best token launch radar: 200 pre-token protocols ranked by an implied value computed from the DefiLlama snapshot's own figures — TVL × a category multiple (the median market-cap / TVL of live tokens in the same category, computed from the snapshot) × 7-day growth × chain breadth × maturity with no token — with a concrete farm plan for each one, in a sortable, filterable dashboard with a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
